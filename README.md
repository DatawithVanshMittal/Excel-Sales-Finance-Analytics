# Excel-Sales-Finance-Analytics

## Project Overview

This project focuses on analyzing Sales and Finance data using Microsoft Excel to generate meaningful business reports and support data-driven decision-making.

The project covers customer performance, market performance, sales targets, and Profit & Loss (P&L) analysis across different periods and markets.

---

## Sales Analysis

### Project Objectives

- Analyze customer performance
- Compare market performance with sales targets
- Identify sales patterns and key performance indicators (KPIs)
- Support business decision-making through sales analysis

### Reports

- Customer Performance Report
- Market Performance vs Sales Target Report

---

## Finance Analysis

### Project Objectives

- Analyze Profit & Loss (P&L) performance
- Analyze P&L across fiscal years and months
- Compare P&L performance across different markets
- Support financial planning and decision-making

### Reports

- P&L Statement by Fiscal Year
- P&L Statement by Months
- P&L Statement by Markets

---

## Tools & Skills

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- Data Modelling
- ETL (Extract, Transform, Load)
- Date Table Creation
- Fiscal Month & Quarter Analysis

---

## Key Learning Outcomes

- Developed structured Sales and Finance reports using Excel
- Worked with Power Query for data transformation
- Created data model relationships using Power Pivot
- Used DAX to create calculated columns
- Developed user-focused business reports
- Improved understanding of Sales and Finance analytics
